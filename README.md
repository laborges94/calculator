# Calculator

Um pequeno projeto em C# que implementa uma calculadora simples.  

## O que é

- Projeto desenvolvido em C#, a linguagem predominante no repositório.  
- Permite realizar operações básicas de cálculo (como adição, subtração, multiplicação e divisão).  
- Possui uma estrutura simples, ideal para aprendizado, demonstração ou como base para futuras extensões.

## O que pode ser feito no futuro

Aqui estão algumas ideias de melhorias ou extensões:

1. **Operações avançadas**  
   - Logaritmos  
   - Funções trigonométricas (seno, cosseno, tangente)  
   - Conversões (por exemplo: radianos ↔ graus)  

2. **Interface de usuário mais rica**  
   - Adicionar uma UI que se assemelhe a uma calculadora de bolso

3. **Suporte a histórico de operações / memória**  
   - Registrar operações anteriores para revisão  
   - Funções de memória (M+, M-, MR), como em calculadoras físicas  
   - Exportação ou impressão do histórico  

5. **Extensões para cálculo científico ou financeiro**  
   - Módulo financeiro: amortização, juros compostos, investimentos  
   - Módulo científico: cálculo matricial, estatística básica, álgebra linear

# Calculator (English Version)

A small C# project that implements a simple calculator.

## What it is

- A project developed in C#, the predominant language in the repository.  
- Allows performing basic math operations (such as addition, subtraction, multiplication, and division).  
- Has a simple structure, ideal for learning, demonstration purposes, or as a foundation for future enhancements.

## What can be done in the future

Here are some ideas for improvements or extensions:

1. **Advanced operations**  
   - Logarithms  
   - Trigonometric functions (sine, cosine, tangent)  
   - Conversions (e.g., radians ↔ degrees)  

2. **Richer user interface**  
   - Add a UI similar to a handheld calculator

3. **Support for operation history / memory**  
   - Save previous operations for review  
   - Memory functions (M+, M-, MR), as found in physical calculators  
   - Exporting or printing the history  

5. **Extensions for scientific or financial calculations**  
   - Financial module: amortization, compound interest, investments  
   - Scientific module: matrix calculations, basic statistics, linear algebra
